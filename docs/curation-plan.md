## 3. 评审规程

### 3.1 评审者

- 每轮一个**全新、无上下文**的评审：不给仓库，不给对话，不给我的推理；只给 §3.2 的截图与纯文本、本节评分表。
- 两个角色各评一次，每项取**较低分**：
  - (a) 加拿大科技公司招聘专员，每个作品集看 30 秒；
  - (b) 安全团队招聘经理，愿意花 3 分钟判断技术是否真实。
- 输出：每项分数 + 1–3 条可执行建议，每条写明是哪张截图、哪个元素、改成什么。

### 3.2 机位（每轮相同，`scripts/shots.mjs`）

| 编号 | 桌面 1440 × 900 | 手机 390 × 844 |
|---|---|---|
| F1 | 首访 1.5 s | 首访 1.5 s |
| F2 | 首访 5 s | 首访 5 s |
| F3 | 首访落地：入场结束、主档案自动打开后 | 同左 |
| F4 | 回访到达档案馆（HUD 已出现） | 同左 |
| F5 | 精选第 1 个（MCP）在档案馆里的面板 | — |
| F6 | Index 打开 | — |
| F7 | MCP 项目页首屏 | MCP 项目页首屏 |
| F8 | Coast Capital 首屏 | — |
| T1 | 首页纯文本（无 JS） | — |

### 3.3 评分锚点

| 项 | 看哪里 | 9–10 | 6–8 | ≤ 5 |
|---|---|---|---|---|
| R1 前 5 秒：是谁 | F1–F2 | 姓名 + 唯一头衔 + 一句论点，无需交互即可读 | 有姓名头衔，但头衔不止一个或论点需交互 | 前 5 秒的主要内容不是他 |
| R2 前 15 秒：强在哪 | F1–F3 | 至少 2 个有来源的数字和一个雇主名可见 | 有数字但要找 | 没有数字 |
| R3 30 秒：看哪几个 | F3–F6 | 不用探索就知道“精选 N 个”及入口和顺序 | 有入口但要开 Index | 要翻抽屉才知道哪些重要 |
| R4 可信 | F7–F8 | 首屏有：我的部分（团队项目写具体）、一条证据、头号数字、下一个去哪 | 缺其中一项 | 缺两项以上 |
| R5 个人感 | F1–F4 | 首帧至少一个元素只属于他，换掉名字画面就不成立 | 只有姓名和文案是他的 | 换掉名字谁都能用 |
| R6 克制 | 全部 | 列不出“删掉也不影响 HR 理解”的元素 | 每列出一个扣 1 | — |
| R7 文案 | 全部 | 找不出读起来像 AI 写的句子 | 每处扣 1，附原句 | — |
| R8 纯文本 | T1 | 让评审用 3 句话总结此人和他最强的 3 个证据，结果与意图一致且提到精选项目 | 总结正确但证据不对 | 总结错误 |

### 3.4 硬门槛（任何一条不过，本轮不过）

`DESIGN.md` 的 Rejected 清单；页面上的数字在 `numbers.test.ts` 有来源；有意义的文字对比度 ≥ 4.5:1；390 宽无横向滚动；verify 通过。

### 3.5 记录

`docs/review-log.md`：日期、提交、R1–R8 分数、采纳与不采纳的建议（不采纳要写理由）。

## 4. 减法清单（S4）

| 元素 | 现在在哪 | 去向 | 理由 |
|---|---|---|---|
| `CRYPTO-SHRED ✕` | 文件顶栏右侧 | V-FILE（“这个网站怎么保护你”） | 占着“关闭”的位置；对 HR 是陷阱 |
| `Watermarked to V-xxxx` | 文件顶栏中间 | V-FILE | 对理解他没有帮助 |
| UEBA 风险条 | 页脚 | V-FILE | 同上 |
| `0 trackers · 0 cookies · headers` | 页脚 | V-FILE | 对安全工程师有趣，放进彩蛋档案而不是主路径 |
| `Access log` tab | 每个文件 | 只在 V-FILE | 每个文件都多一个和他无关的 tab |
| 访客攻击画像 | 入场 | 由 S2 决定 | — |

保留（主路径上的两个招牌交互）：开档解密扫光、SENTINEL-1。另保留引线、图例、键盘提示（12 s 后自动隐藏）。

## 5. 假设与风险

| # | 假设 / 风险 | 对策 |
|---|---|---|
| A1 | 无 GPU 截图的光影与真机不同 | 云端评审只评层级与内容；光影在你的机器上看 |
| A2 | LLM 评审分数漂移 | 固定机位 + 锚点 + 两个角色取低分 + 同一提交复跑分差 ≤ 1 |
| A3 | 云端每张截图约 1–2 分钟 | 机位控制在 13 张，并行 3 个；你的机器上快得多 |
| A4 | 抽屉重排（S6）牵动 slot、e2e 与内景顺序 | 单独一步、单独提交；内景六站顺序不动 |
| A5 | 减法（S4）改动 e2e 断言 | 同一提交里更新测试 |
