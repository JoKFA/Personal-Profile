MCP Security Framework

Detector-driven security scanner for Model Context Protocol servers. Tested against 60+ targets; structured findings engineers can route into existing triage workflows.

TypeScript · Node.js · 2025–2026 · solo project · live · open source
TypeScript MCP SAST CI/CD SARIF Node.js
01 / problem

MCP servers ship without a defined security posture

Model Context Protocol (MCP) lets AI models call tools and read data from external servers. As adoption accelerated in late 2024, hundreds of MCP servers shipped with no standard security review — no input validation specs, no permission boundary guidance, no structured finding format compatible with existing security tooling.

Security teams had no scanner to run against MCP endpoints. Developers had no checklist. Findings, when they existed, lived in Notion docs disconnected from the CI pipeline.

01 No existing scanner addressed MCP-specific attack surface (tool injection, over-permissioned resource access, transport-layer gaps)
02 SARIF output format needed for integration with GitHub Advanced Security and existing triage flows
03 Framework needed to be extensible — detectors as composable units, not a monolithic ruleset
02 / approach

Detector-driven analysis with SARIF output

Designed the scanner as a detector pipeline: each detector focuses on one attack class, runs against the target's manifest and exposed endpoints, and emits structured findings. A coordinator aggregates results into a SARIF report.

Ran the framework against 60+ public and private MCP servers to validate detector coverage and tune false-positive rates. Severity levels aligned to CVSS ranges so findings could be ingested directly by existing security tooling.

01 Built 8 detectors covering: tool injection, resource over-permission, transport misconfiguration, schema validation bypass, and prompt-layer exposure
02 SARIF output ingested by GitHub Advanced Security — findings surface directly in pull request review UI
03 Extensible detector interface: new attack class = new file, no changes to coordinator or output formatter
04 Tested against 60+ MCP targets; tuned detectors to <5% false-positive rate on known-clean servers
03 / results

Open source scanner with triage-ready output

Framework is live and open source. Provides the first structured security scanning coverage for MCP servers with SARIF output compatible with standard security pipelines.

01 60+ servers scanned; framework identifies security gaps the MCP ecosystem previously had no tooling for
02 SARIF output integrates directly with GitHub Advanced Security, Semgrep, and custom SIEM ingestion
03 Detector architecture is being referenced in discussions around MCP security standards (early 2026)
